## Part A – Responsive UI

Developed a responsive IRP LMS landing page using HTML5 and CSS3.

### Features

- Sticky navigation bar.
- Responsive hero section.
- Learning journey section with five cards.
- Responsive layout for desktop, tablet, and mobile devices.
- CSS Flexbox, Grid, and media queries.
- Footer section.

### Technologies Used

- HTML5
- CSS3

### How to Run

1. Clone or download this repository.
2. Open the `part-a-responsive-ui` folder.
3. Open `index.html` in a web browser.

## Part B – JavaScript Foundations

Implemented JavaScript examples covering fundamental JavaScript concepts.

### Concepts Covered

- Data types and type coercion.
- Input validation using `parseAmount()`.
- `var`, `let`, and `const`.
- Hoisting and the Temporal Dead Zone.
- Function declarations and function expressions.
- Asynchronous loops using `setTimeout()`.
- Difference between `var` and `let` in loops.

### Technologies Used

- JavaScript
- Node.js

### How to Run

Make sure Node.js is installed, then run the following command from the project root:

```bash
node part-b-javascript/bank.js
```
