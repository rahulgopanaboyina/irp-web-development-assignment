# IRP LMS - Web Development Assignment

This project is built as part of the IRP LMS Web Development Assignment.

## Project Structure

```text
irp-web-development-assignment/
├── part-a-responsive-ui/
│   ├── index.html
│   └── style.css
├── part-b-javascript/
│   └── bank.js
└── README.md
```

## Part A - Responsive Web Design

A responsive IRP LMS home page built using HTML5 and CSS3.

Features:

- Sticky navigation bar
- Responsive hero section
- Learning journey cards
- Desktop, tablet, and mobile layouts
- CSS Flexbox and Grid

### How to Run

Open `part-a-responsive-ui/index.html` in a browser or use the VS Code Live Server extension.

## Part B - JavaScript Foundations

JavaScript examples covering:

- Type conversion and coercion
- Input validation using `parseAmount()`
- var, let, and const
- Hoisting and Temporal Dead Zone
- Function declarations and expressions
- Asynchronous loops using setTimeout

### How to Run

Install Node.js, open the project folder in a terminal, and run:

```bash
node part-b-javascript/bank.js
```

- HTML5
